CPU vs GPU vs NPU(Systolic Array) 데이터 흐름 비교

메모리 접근 횟수와 연산 장치 간 데이터 전송 방식의 결정적 차이

CPU (직렬 / 메모리 병목)
• 메모리 ↔ ALU 간 데이터를 매번 오고 가며 순차 처리합니다.
• 데이터 이동 거리가 길어 메모리 병목(Memory Wall)과 전력 소모가 큽니다.
GPU (병렬 / 레지스터 중심)
• 수많은 코어가 캐시/레지스터 파일에 동시에 접근합니다.
• 병렬 처리량은 높지만, 레지스터 읽기/쓰기 전력 소모가 지속적으로 발생합니다.
NPU (Systolic Array / 공간 분할)
• 가중치는 PE에 고정(Stationary)됩니다.
• 데이터가 이웃 PE로 직접 전달되어 메모리 접근 없이 극도의 전력 효율을 냅니다.
