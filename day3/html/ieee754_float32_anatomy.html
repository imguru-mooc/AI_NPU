왜 배우는가 — 양자화(PTQ)로 가는 길

FP32 = 32 bit / 값
→
INT8 = 8 bit / 값
→
메모리 ¼ · 데이터 이동 에너지 대폭 절감
NPU에서 INT8 양자화가 왜 효과적인지 이해하려면, 먼저 FP32가 32비트를 어디에 쓰고 있는지 알아야 합니다. 지수 8비트가 만들어 주는 넓은 동적 범위(±3.4×10³⁸)를, 양자화는 scale·zero-point라는 별도 파라미터로 대체합니다.
