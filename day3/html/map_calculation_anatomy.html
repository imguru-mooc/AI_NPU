왜 배우는가 — 배포 파이프라인과의 연결

conf threshold ↑ → P↑ R↓
conf threshold ↓ → P↓ R↑
mAP = 모든 threshold를 한 번에 평가
post_process의 confidence threshold를 조정하는 것은 PR 곡선 위의 한 점을 고르는 일입니다. mAP는 곡선 전체를 요약하므로 threshold와 무관한 모델 자체의 성능 지표가 됩니다. 중복 탐지가 FP가 되는 것을 봤듯이, NMS가 mAP를 지키는 방어선입니다. 참고: COCO의 mAP@[.5:.95]는 IoU 임계값 0.50~0.95(0.05 간격, 10개)에서 이 계산 전체를 반복해 다시 평균한 값입니다.
